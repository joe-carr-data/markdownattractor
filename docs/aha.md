# aha.md — things learned the hard way

Dated one-liners. Newest first. Pruned monthly: entries that became rules graduate to `.claude/rules/`, the rest go to `archive/aha-YYYY-MM.md`. Keep under 60 lines.

- 2026-11-18 — A figure measured in one mode is not what the default does. "Raw-only success@5 0.883" came from `mda eval`'s raw-only run; a real keyless folder searched in the default mode, where the deterministic cards and vectors of heading-only sections outranked raw matches (20 of 60 against 49 with `--raw`). Found by recording the demo, not by a benchmark. Measure the path the user takes.
- 2026-11-18 — Run the cheap baseline before building the feature, not after: an agent with file search and git (Haiku, 40 turns) took an afternoon to set up and beat `mda check` on precision (87 % against 51 %), recall and cost on the development half. A fixed pipeline (candidates, then one judgment per pair) spends its budget on pairs that share a word; the agent reads the diff, picks the one term that matters and reads around each hit. Three days of code went in before that comparison existed.
- 2026-11-18 — `target/debug/incremental` grew to 50 GB and filled the disk during an evaluation (347 MB free; a test failed with "Write failed"). Check `df` before long runs; `rm -rf target/debug/incremental` is safe and costs one slow rebuild.
- 2026-11-18 — "Re-read before printing" has to mean after the last model call, for every finding, against the exact text that was judged: a check made when each pair is judged lets the first finding go stale while the second is waiting on the model, and a hash of the section alone misses a status added to the file's front matter (Codex on `mda check`). Same review: a retry is a call, so the budget is read before each attempt, not each pair.
- 2026-11-18 — A release built everything twice and cold: a dry run on the release branch, then the same code again for the tag, and GitHub shares a compile cache only from the default branch, so neither run could read the other's. One publishing run on `main` (`gh workflow run Release --ref main -f publish=true`) builds once, checks, and creates the tag last; the tag can no longer exist without its binaries.
- 2026-11-18 — One binary path shared by all plugin versions lets an old session undo an update: every open session keeps the plugin copy it started with and re-runs its SessionStart hook after each compaction, and the hook installed "the version of my copy" over `bin/mda` (seen: this session put 0.2.3 back over 0.2.6 at its own compaction). Shared state written by a hook is keyed by the plugin version (`bin/mda-<version>`), and `ls -la` + `--version` on the installed file is the check, not the plugin list.
- 2026-11-17 — A change to a script the release workflow runs must be tried in that workflow before the tag: the data-folder fix made the release's own install check fail, so v0.2.5 was tagged with no binaries while the marketplace already served 0.2.5. Grep `.github/` for every script a PR touches, and run the Release workflow by hand (`workflow_dispatch`, no publish) on the release branch before tagging.
- 2026-11-17 — `CLAUDE_PLUGIN_DATA` in a Bash-tool shell is not yours: it held the codex plugin's directory in two sessions, which is the real cause of "mda binary not found" on 0.2.3 (the 0.2.4 fix then downloaded into codex's folder). Check that an inherited plugin variable names this plugin before using it; a test with a foreign value would have caught both.
- 2026-11-17 — "Read-only" git is not: `blame` runs a configured textconv, `diff` against the working tree runs clean filters and the fsmonitor hook, and any object read in a partial clone can start a fetch. Found only because a second review round asked for each mechanism by name with a reproduction. Build git commands in one place, deny by default there (`protocol.allow=never`, `--no-textconv`, `--no-filters`, no working-tree diff), and keep one test that configures every hook to touch a marker.
- 2026-11-17 — A session-start hook is not a precondition: Claude Code can start a plugin's MCP server before the hook that downloads its binary has finished, and the owner's second session got "mda binary not found" on 0.2.3. Anything a launcher needs it must be able to fetch itself; the first-run gate script ran the hook first and so could not see this.
- 2026-11-17 — A release can be blocked by news, not by code: `cargo deny` failed on a version-bump PR because `chrono` was declared unmaintained that week (RUSTSEC-2026-0543, through `rmcp`). Run `make check` before promising a release time; an unmaintained notice with no vulnerability goes in `deny.toml` with its reason.
- 2026-11-15 — A grader's citation rule is part of the product contract: asking agents for `path.md:11-13` made 72 of 123 answers "no resolvable citation" under an extractor that wanted the token to end in `.md`. Test a new answer format against the grader before measuring it, and measure a wording change against a control arm in the same run, not against an old table.
- 2026-11-15 — A chain of harness steps joined with `;` ran on after a refused run and started grading the wrong directory; nobody noticed until the owner asked. Join counted steps with `&&`, start a short waiter beside every long job that checks the first rows exist, and move a copied run set aside before running in a copied `$RUN`.
- 2026-11-15 — A demo that shows retrieval looks like what Claude and grep already do, however exact the provenance; in a real take Claude also stated a wrong "last changed" date although the index held the right one. Record the product's own output, check every date on screen against the index, and never reuse a section text already summarized (cards are keyed by hash, so the summary step vanishes).
- 2026-11-15 — serde cannot read a `u128` back through an internally tagged enum (`#[serde(tag = …)]` buffers into `Content`, which has no 128-bit integer): `mda watch` died at the first embedding event in v0.2.0. Durations on the wire are `u64`; a wire type gets a round-trip test per variant.
- 2026-11-10 — "Tracked and clean" does not mean git's lines are your lines: filters, CRLF conversion and a lone CR make blame describe other bytes. Date from git only after proving it (blob id of the bytes you read equals the tree's, no CR, the parse equals the stored rows), and write through a conditional transaction. Three design reviews before code found 31 problems; the first test run then passed.
- 2026-11-10 — A test that opens the store before the daemon has created it races the daemon's own first open (intermittent: the daemon dies or the test panics). Wait for the daemon's socket first, as the older daemon test does.
- 2026-11-10 — mda's times are filesystem times, not git: in a fresh clone every document is "created" and "changed" at clone time. Every benchmark corpus was such a copy, so the recency prior (half-life 30 days) was neutral in every published table; on realistic ages it pushed a 2-year-old ADR from 2nd to 4th behind a 2-day-old runbook. Test time features on corpora with real ages (`scripts/demo/make-corpus.py`).
- 2026-11-10 — A plugin's root `.mcp.json` is also a *project* MCP config whenever Claude Code runs inside the plugin's own repository, where `${CLAUDE_PLUGIN_ROOT}` is unset, so contributors see a failing server. Declare plugin MCP servers inline in `plugin.json` (an object, not a path: naming a standard path there breaks the marketplace install, see 2026-09-22). `claude mcp list` shows both entries side by side.
- 2026-10-27 — A citation rule written for one corpus is a measurement artefact on another: T6's bare-token rule (`whitespace-delimited token ending in .md/.mdx`) counts "files ending in `.md`" and a file named outside the corpus (`FROZEN.md`, `CLAUDE.md`) as unresolved citations, so three docs questions failed grounding for every arm alike (8–9 of each arm's 75 rows). Published as measured, split by cause beside the gate; never rescored.
- 2026-10-27 — mda's walker is git-aware and skips hidden directories *and* tracked files that a `.gitignore` pattern matches; qmd skips the hidden ones only. Check a corpus's indexed-document count against its inventory before questions are drawn (private: 595 and 600 of 821 pages; no question was affected because candidates come from the store).
- 2026-10-27 — Never edit a bash script while any invocation runs (bash reads it incrementally and executes garbage from the old offset); `pkill -f` on a pattern the calling shell's own command line contains kills the caller; a heredoc body that contains its own delimiter ends it early. Each looked like a harness bug and cost a model-spending rerun (M9).
- 2026-10-16 — Write the mechanism from the traces, not from the design: the T5 page first said mda "searches its index, then opens git"; every one of its 240 counted runs began with Bash. Codex caught it at the publication check. Before a sentence says what an agent did first, count first tool calls.
- 2026-10-16 — Under equal evidence (history in Bash for every arm) the index arms answer from git and the probes barely activate; a permission rule that denies compound commands hits the arm with no fallback hardest (T5 git on Prisma: 0 of 19 runs without a successful git call). Measure the tool choice you created, and read the "arm tool used" column before the correctness one.
- 2026-10-16 — Four T5 freeze rewrites in a day, all harness-only, each because a new preflight or replay check path first ran under the freeze: `grep -q` on a live pipe under `pipefail` (SIGPIPE upstream, like `head`), a jq pipe rebinding `.`, a clone whose `main` was the fetched tip beyond the pinned revision, a "nothing failed" completion rule that a failed card tripped. Rule: every check a harness will run under a freeze is exercised in the dry run first, and a counted run only starts after the preflight code path has passed once end to end; and a clone's refs are pinned at setup, never assumed.
- 2026-10-15 — A replayed working copy is single-use on macOS: setting an earlier mtime moves the file's birth time down to it and nothing moves it back up, so a second replay in the same clone inherits the first one's `created_at` (219 of 263 docs off by one step in the T5 dry run). `t5.sh replay` now refuses a copy whose files are older than its `.git`; a counted replay starts from a fresh clone.
- 2026-10-15 — `freeze.sh --check` is a run-time gate, not a post-publication invariant: every published freeze (T1, T2, T4) reports "code paths changed since the frozen commit" on today's tree, by design. What protects a table is that its freeze precedes its rows in git and the archive regenerates; a pinned harness may be fixed after publication (the `t4.sh purge` backup landed in M8). Corrects the 2026-09-27 line that said otherwise. Also: never rebuild the binary during a counted run — the harness calls `$MDA` per step.
- 2026-09-27 — Two T4 lessons. A probe or endpoint question that names the page proves nothing about an arm's tool: the agent reads the file (qmd's tool used in 0 of 3 probes); ask it to find the fact. And an aborted attempt lives on in every hash-keyed cache: three sections summarised during the aborted run came back as cards in under 2 s on the counted run (`reused=1`); purge summaries and vectors before counting, and record hashes that a run mutates under the freeze's Runtime, never its checked Inputs.
- 2026-09-26 — Two graders on the same 0–6 rubric can disagree by two to three points systematically: Astra (through `codex exec`) scored 1.1–2.8 mean where Sonnet and Fable scored 3.8–4.9 on the same answers, so a "resolve by the panel mean" rule fired on 18–28 of 30 answers. Calibrate the panel on a fixed sample and publish the offsets before making the mean the score of record; publish both analyses, never only the adjudicated one.
- 2026-09-25 — A grounding check is only as fair as its citation resolver: qmd's MCP returns `<collection>/<path>` and models cite bare file names, so the first pilot grading marked 17 of 20 qmd answers "no resolvable citation". One declared rule for every arm (exact path, or the unique suffix after a `<project>/` prefix) fixed that; the remaining failures are the rubric's strictness on unsupported claims, which is a pre-freeze decision, not a resolver bug.
- 2026-09-25 — Competitor caches survive between the scoring run and the latency run: qmd's `llm_cache` served every re-asked Supabase question in 0.6 s (44–135 s uncached). Measure latency on questions the arm has not seen, or clear the arm's cache on a copy, and say which; "cold" = new process, not cleared caches.
- 2026-09-24 — Never edit a bash script that a detached run is executing: bash reads a script incrementally, and rewriting `t1.sh` while a chain was between two compound commands produced `syntax error near unexpected token` and a lost project run. A driver change during a run also means a re-freeze (scripts/eval is a code path); batch script fixes before launching, and snapshot the scripts into the run directory if a long run must overlap edits.
- 2026-09-24 — Order pre-declared tuning candidates cheapest-first. The greedy list put the two re-embedding candidates (≈ 1 h each) ahead of five minutes-long search-time knobs; the stop rule fired on the expensive pair and the cheap ones could then only be run as a post-stop, information-only extension (two of which clear the screen, unadoptable). Also: a bootstrap of the objective before choosing thresholds; 0.01 was ≈ 0.2 SE on these dev splits.
- 2026-09-24 — `git add <dir> && git commit` commits the *whole* staged index, not the directory: after a `reset --soft` that keeps an old text-bearing file staged, the first "scoped" commit carried the secret-scanner hit and GitHub push protection named that commit (`git show <sha>:<file>`). Unstage everything (`git reset`) before staging per group, and scan every commit of the branch for key-like strings before pushing.
- 2026-09-23 — The owner's shell exports `GEMINI_API_KEY` and `OPENAI_API_KEY`; a headless `claude -p` running graphify's skill found the Gemini key and did its whole docs extraction through Gemini (then `pip install openai`), silently breaking "every model call through the Claude login" and the arm's fairness profile. Every arm script now unsets provider keys before spawning anything, and the preflight refuses to certify with one present.
- 2026-09-23 — An isolated `CLAUDE_CONFIG_DIR` has no login ("Not logged in · Please run /login"): a competitor's skill and hooks go into the checkout *copy* at project level (`graphify install --project`) and the session runs with `--setting-sources project`, never into the owner's real Claude Code configuration.
- 2026-09-23 — At full card coverage, vectors are not the free win the golden set suggested: cards + raw beat raw on every DocsQA project (+0.08 to +0.24 success@5), but adding the vector list helped GitHub Docs and Supabase, did nothing on Prisma and cost Tailwind 0.04. Tuning candidates exist for exactly this (embedding text, list weights, RRF k); they are tried on the dev split only and the loss is on the page until then.
- 2026-09-23 — The Bash tool's shell here is zsh: an unquoted `$PROJECTS` in a `for` loop is one word, not four. Scripts run under `bash` (shebang) are fine; ad-hoc loops in the tool need `bash -c` or `${=VAR}`.
- 2026-09-23 — A freeze cannot record the commit that contains it: `FROZEN.md` names the source commit of the code that produced the numbers, and `freeze.sh --check` requires the code paths that change a number (`crates`, `prompts`, `skills`, `scripts/eval`, lockfile, toolchain) unchanged from that commit to HEAD, instead of comparing SHAs.
- 2026-09-22 — `taiki-e/install-action` failed on every Windows image for four hours straight ("installation failed due to bash startup failure", partner-runner-images#169, `windows-2025-vs2026` and `windows-2022` alike), blocking every PR. Reruns and an image pin are not a fix when the installer itself is broken: Windows now runs `cargo test` instead of nextest and needs no installer.
- 2026-09-22 — Partial cards make hybrid search *worse* than raw: on Tailwind with 14% of sections carded, cards+raw fell from 0.60 to 0.36 success@5 and hybrid to 0.12, because reciprocal-rank fusion hands every carded section a place on two extra lists. A benchmark row needs full coverage, and a daemon in its first backfill may rank worse than raw until it finishes (product follow-up in the plan).
- 2026-09-22 — The dataset's "evidence anchors" are rendered headings: backticks kept, Liquid variables expanded, page title as a section. Normalising both sides took GitHub Docs from 137 to 183 of 222 found; the rest are `{% data reusables %}` includes the source cannot show. State the number and the cause, do not claim "passed".
- 2026-09-22 — DocsQA at 100% label coverage on all four projects, but raw BM25 over section text answers only 22–60% of the dev questions in the top 5: real community questions are long and paraphrased, the AND query almost always falls back to OR, and OR over twenty terms takes ≈ 0.5 s per query on a 23K-section corpus (one row read per candidate, 120 candidates per list). The floor is published as a floor; cards and vectors are the product's answer, and the candidate depth is the latency lever.
- 2026-09-22 — Codex on the lean-payload PR caught me retyping numbers: the "before" means in the A/B table were wrong and the after-medians used a different denominator. Tables are regenerated from the raw grades by a script, never typed from memory; and a run set gets a manifest before it is graded, so missing or duplicate rows are visible.
- 2026-09-22 — Codex on the `.mdx` PR: a rule keyed on text ("a line starting with `import `") silently ate the first paragraph of any `.md` file that began with the word; a line scan inside an HTML block promoted `# comment` lines from a nested fence to headings and document titles. A dialect is a property of the file (`Flavor::of_path`, used by every re-parse), and a scan inside a block must carry the block's fence/comment/`<pre>` state.
- 2026-09-22 — MDX needed less than feared: comrak already keeps 99.7% of the headings in 1,711 real Docusaurus/Nextra pages; what was actually missing was the *title* (every page: it lives in front matter or `export const title`, not in an H1) and headings glued to a JSX closing tag (`</Admonition>\n## How it works`, an HTML block that runs to the next blank line). Measure on the real corpus before designing a tolerant parser.
- 2026-09-22 — `plugin.json` must not name the standard component paths (`hooks/hooks.json`, `skills/`, `.mcp.json`): Claude Code loads those automatically and a marketplace install then fails with "Duplicate hooks file detected". `claude plugin validate` and a `--plugin-dir` load both passed; only a real marketplace install (from a local path works: `claude plugin marketplace add /path/to/checkout`) caught it. Test installs that way before tagging.
- 2026-09-22 — History was rewritten (git filter-repo) to scrub two workspace ids before the repo went public: every commit SHA quoted in docs written before 2026-09-22 15:30 UTC (review pins, handoffs) refers to the old history; look commits up by message. Old objects can linger on GitHub until its GC or a support request.
- 2026-09-22 — A/B on the 450-line golden corpus: parity 12/12, but the index reads *more* source tokens (median 1,305 vs 341) because eight hits with cards cost ~1.3K tokens whatever the corpus size and one grep+read finds the answer in a few hundred. G3 is a claim about big corpora; the small-corpus number is published as the plan promised.
- 2026-09-22 — `claude -p --bare` skips keychain reads, so a headless run answers "Not logged in"; `--setting-sources ""` plus `--strict-mcp-config` gives the lean, fair session the A/B needs without it. Variadic flags (`--tools a b c`) swallow the prompt: put `--` before it.
- 2026-09-22 — The prebuilt static ONNX Runtime (`ort-sys` rc.13) is built against GCC 13's libstdc++: linking on `ubuntu-22.04-arm` fails with `__cxa_call_terminate` undefined. Release builds run on 24.04; Linux users need glibc ≥ 2.39.
- 2026-09-22 — `gh workflow run` needs the workflow file on the default branch (404 otherwise): a new workflow's dry run happens after its PR merges, not on the branch.
- 2026-09-22 — Codex through a bare `codex exec --sandbox read-only --ephemeral` from the sandboxed shell fails to initialise ("Operation not permitted"); the shared companion runtime the codex-rescue skill provides works. Say so in the review prompt.
- 2026-09-22 — A hook that calls the binary with a flag the *installed* binary does not have fails silently (`>/dev/null 2>&1 &`). I added `--no-example` to `bootstrap.sh` before the binary had it and spent a debugging round on "the SessionStart hook does not start the daemon". Ship script and binary changes in the same PR and re-copy the binary before testing a hook.
- 2026-09-22 — macOS temp dirs have two spellings (`/var/…` and `/private/var/…`); a redaction that replaces `$HOME` as given misses the canonical form. Redact both.
