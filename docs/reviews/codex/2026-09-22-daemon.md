## 4. Patterns → rules

- **A watcher event is a hint, never a fact; and reads are not events.** Filter `Access` at the source; decide by looking at the filesystem. (→ `docs/aha.md`)
- **Read-then-write transactions begin `IMMEDIATE`.** The busy timeout cannot rescue a deferred transaction that needs to upgrade. (→ `.claude/rules/rust.md`)
- **A stopped run is not a failed section.** Environment failures (cancel, stop, bad key, dead server) defer; only the model's answer or the validator can fail a section.
- **Exclusivity comes from an OS file lock, never from "does the socket answer".**
- **Every file under `.markdownattractor/` is created without following symlinks.**
