## 1. Findings (Codex, condensed; file:line against `076f7ee`)

| # | Sev | Finding | Fix |
|---|---|---|---|
| F1 | High | Both panel aggregation jq programs failed to compile (`$as` is a jq keyword; a comparison inside an object needs parentheses), after the model judgments had been paid for. | Bindings renamed, expression parenthesised (and an apostrophe inside a jq program removed); both commands smoke-tested end to end with stored judgments. |
| F2 | High | Grounding could pass on incomplete evidence: unresolvable citations were skipped, pages beyond the first four dropped, pages over 120,000 chars silently truncated; the comment claiming truncation fails the answer was false. | Every citation's resolution is recorded; an unresolvable path or an oversized page makes the answer ungrounded with the reason (`evidence_policy`); every resolvable page is checked whole, in batches of four, and the answer is grounded only when every batch says so. The accepted citation syntax (a repository-relative `.md/.mdx/.markdown` path) is declared in the runbook. |
| F3 | High | Resume compared manifests with `launches`, `mda` and `source_commit` stripped, so new rows could come from another binary, rules file, graph or launch configuration. | The manifest carries the binary's sha256, the rules' sha256 and the preamble; a resume compares everything but the timestamp and the source commit, with only the temporary file names inside the launch records normalised; a difference refuses the resume and names the diff. |
| F4 | High | The analysis counted rows instead of validating run identities (runs `1,2,4` looked complete), accepted rows for unknown arms or questions, and without a manifest could hide absent questions. | Every row is validated against the manifest (unknown question or arm, run outside `1..=runs` → error); a skipped run number is a missing run; the CLI requires `--manifest` (`--no-manifest` is diagnostic and says so). Tests and the failure matrix cover the refusals. |
| F5 | Med | The card sample sorted by the card hash, not the seeded key; only metadata-bearing cards were sampled without saying so; cards whose section was not in the store vanished. | Sorted explicitly by the key (jq `sort_by`); `sampled_from` and `sections_missing_from_store` in `cards.json`. |
| F6 | Med | The card audit judged the raw date phrase only (a wrong ISO normalisation could pass) and accepted shortened or empty verdict arrays. | Each date is audited as "raw → iso (precision)" and is supported only when the phrase is in the text and the normalisation is right; a verdict that does not cover every value once, in order, is invalid (null) and counted as incomplete. |
| F7 | Med | `Savings.questions` was one denominator for three ratios that each dropped questions (missing metric, zero mda denominator). | `MetricRatio` per metric: its own `questions`, `excluded_missing`, `excluded_zero_denominator`; a zero mda value is excluded and counted, never divided by; the CLI prints all three. |
| F8 | Med | Clamping per-turn deltas at 0 changed the estimand of rule 0.7 and hid the size of context reductions. | Rows carry `source_tokens` (clipped, labelled), `source_tokens_signed`, `source_tokens_negative_total` and the number of clamped turns; the runbook states both measures and the policy. |
| F9 | Med | Panel resolutions never reached the analysis. | `panel.sh regrade` writes `panel/grades.adjudicated.jsonl` (the resolved score in place for the sampled answers, the Sonnet score kept beside it, `triggered` recorded); `t2.sh analysis --adjudicated` analyses it; the page reports both. |
| F10 | Med | `grade` truncated `grades.jsonl` and panel reruns truncated member files, against the runbook's promise to keep independent reruns beside originals. | Versioned files (`grades.<stamp>.jsonl`, `regrade-<member>.<stamp>.jsonl`, `cards-<member>.<stamp>.jsonl`), the unstamped name replaced atomically at the end; a rerun never overwrites an earlier complete file; grader and stamp recorded per row. |
| F11 | Med | A retried run reported only the final attempt's tokens and cost while wall-clock covered every attempt. | Every attempt records its own input/output tokens, cost and turns; the row carries `cost_usd_all_attempts` and `attempts_made`; the analysis keeps the final attempt's metrics (a failed attempt contributes nothing to a saving), the operational total is beside it. |

## 2. Answers (condensed)

- **(a)** The `message_delta` usage reconstructs the turn totals (grep 52,423, mda 48,993 in the smoke traces); the subtraction is the declared net-context-growth measure, valid under continuous context; negative deltas are now reported with their magnitude beside the clipped sum.
- **(b)** Failures behave as the plan says for valid rows; the median-with-zeros is the conventional median (a single failure need not lower it). The failure matrix covers the analysis and `status`, not the runner/grader boundary end to end — stated in the runbook.
- **(c)** The three gates are per pair as written; the interval is of the mean paired difference of question medians, which is what rule 0.4 says; the median-of-ratios saving is a typical-question, completed-only comparison, now with per-metric denominators.
- **(d)** Whole pages are the right evidence; strictness must be consistent — now every citation is resolved or the answer fails, and the citation syntax is declared before measurement.
- **(e)** Same preamble, model, max-turns, timeout and retries for every arm; graphify's project settings and checkout copy are its installed configuration and are published with hashes; execution is not deterministic beyond the model (concurrency, caches, rate limits) and the runbook says so.
- **(f)** The trigger is declared: either panel member differs from the Sonnet grade by more than one point → the panel mean; the strategy's wording did not settle it, and the scripts no longer call it "verbatim".
- **(g)** Runbook §5c now states the resolved model ids and hashes in the manifest, the exact-manifest validation and the expected/present/error/missing counts, signed vs clipped deltas, retry accounting, per-metric savings denominators, the citation syntax and evidence policy, the panel trigger and the adjudicated analysis, versioned grading files, the failure matrix's actual coverage, the sample-size assertion, and the answer count (1,050 with graphify on two projects, not 1,200).
