## 4. Patterns → rules

- **Anything that parses a tool argument must be total**: no panicking constructors, no unchecked arithmetic; the MCP server aborts on panic.
- **"Ready" means every artifact is present**, not "a directory with the right name exists".
- **Every filesystem touch goes through `safe_join`**, including diagnostics such as `stale()`; regular files only, bounded sizes.
- **A degraded optional stage never fails the whole query**: embeddings, vectors, the daemon's embed pass all fall back to lexical.
