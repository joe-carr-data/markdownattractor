## 1. The options put to Codex

- **A** — proceed to M4 with the pre-tuning defaults, exactly as pre-registered.
- **B** — run c3–c7 as a labelled exploratory extension and adopt a passing candidate before the freeze (amends the stop rule after seeing the data).
- **C** — run c3–c7 for information only, keep the defaults regardless; or amend the stop rule by candidate family before running.

Evidence supplied: the ledger (baseline 0.5014; c1 0.4916; c2 0.4824; stop rule fired), scored dev denominators 49/37/12/25, the cost asymmetry (c1–c2 re-embed, c3–c7 are minutes of search-time config), the pooled-label diagnostic, and a bootstrap of the baseline objective (within-project resampling, 5,000 draws, seed 20260922): SE 0.0486, 95% interval [0.406, 0.597]; one flipped question moves the objective by 0.0051 / 0.0068 / 0.0208 / 0.0100 (GitHub Docs / Prisma / Supabase / Tailwind).

## 2. Codex's reasoning (condensed)

1. **Integrity.** The stop rule fired legitimately and the ledger already says an extension is never a greedy winner. B could be honest if fully disclosed and frozen first, but it cannot preserve the original selection-protocol claim; C preserves it and still answers the cheap engineering questions.
2. **Power.** The 0.01 keep threshold is an engineering screen, not evidence: it is ≈ 0.2 of the baseline objective's SE, and below one Supabase question. Baseline uncertainty is not paired-difference uncertainty; the right statistic is a paired, within-project bootstrap of the difference plus win/loss counts. Rerunning deterministic retrieval adds no sample size.
3. **Overfitting.** Five fixed trials are a bounded search, but selecting their maximum still adds optimism; cheap computation creates no evidence. Prohibiting adoption removes the incentive.
4. **Cost asymmetry** justifies collecting the information, not lowering the evidential standard. c6 (`fetch`) is an adapter parameter, not a product default.
5. **Families.** A family-aware stop rule would have been reasonable prospectively; introducing it after the stopping event resets the fishing budget in response to observed data. A dated amendment makes that transparent, not pre-registered.
6. **Labels.** The pooled diagnostic (one judge so far; helps qmd more on GitHub Docs) is not independent confirmation; the original labels stay the objective.
7. **Guardrail arithmetic.** The 0.02-per-project guardrail permits no net loss of one successful question on any project: even 1/49 = 0.020408… exceeds 0.02. Use unrounded counts and fractions.

Codex's second turn confirmed that the supplied bootstrap matched its own analytical estimate (SE 0.04861) and did not change the recommendation.
