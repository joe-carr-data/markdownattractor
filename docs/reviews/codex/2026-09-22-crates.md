## 2. Findings (Codex, condensed; file:line as reported against `b0814de`)

| # | Sev | Finding | Codex fix |
|---|---|---|---|
| F1 | High | Reads can escape the root: `rel_path` checks only a lexical prefix; `open_section` joins stored paths without checks; a symlink replacing an indexed file reads outside the root (`pipeline.rs:178`, `:451`). | Reject absolute/`..` stored paths; symlink-safe containment. |
| F2 | High | Pipe deadlock: stdin is written before stdout/stderr are drained (`claude_cli.rs:184`); a chatty child blocks both sides until timeout. | Write, drain and wait concurrently. |
| F3 | High | Two concurrent runs can overwrite a `summarized` row with `failed` (`store/mod.rs:737` unconditional UPDATE) and clobber accounting. | Job leases with ownership-conditioned completion. |
| F4 | Med | Read/parse failures are treated as deletions: a file not in `seen` is tombstoned (`pipeline.rs:225/242`). | Track discovered-but-failed; tombstone only confirmed removals. |
| F5 | Med | Retry and failed-attempt usage never reaches the daily budget (only attached cards are persisted; `usage_since` reads `summaries`). | Append-only usage ledger for every attempt. |
| F6 | Med | Cancellation/pool stop marks never-started jobs `failed` (`pool.rs:180`, `pipeline.rs:430`). | Leave unfinished hashes pending. |
| F7 | Med | Rate-limit retries bypass the halved concurrency: retries call the backend directly (`pool.rs:284/346`). | Every attempt acquires admission. |
| F8 | Med | Date grounding accepts a fabricated `iso` (year unrelated to `raw`) and impossible days like Feb 31 (`validate.rs:173/195`). | Validate calendar + precision; tie `iso` to `raw`. |
| F9 | Med | Time/path filters run after the per-index candidate cut (`search.rs:103`) and after the OR-fallback decision. | Filter before limits and before the fallback decision. |
| F10 | Med | A document containing `</section>` can forge the data delimiter (`worker/mod.rs:57`). | Unambiguous encoding; treat apparent delimiters as data. |
| F11 | Med | A single long first line bypasses `max_tokens` (`planner.rs:110`). | Hard cap on a char boundary. |
| F12 | Med | Truncation is only logged, not persisted in provenance (`pipeline.rs:404`, `card.rs:109`). | Persist a `truncated` flag. |
| F13 | Med | Opening a moved section returns the requested id, which now names a different section (`pipeline.rs:466/479`). | Return the resolved current id. |
| F14 | Med | Same hash + same index but shifted lines is reported fresh and the store keeps stale ranges (`pipeline.rs:455`). | Compare the document hash; refresh whenever it changed. |

**Suggested tests:** root containment; subprocess backpressure + cancellation; concurrent ownership; failed-scan preservation; retry admission + accounting.

## 4. Patterns → rules

- **Every path that reaches the filesystem goes through `safe_join`/`rel_path`.** Walker exclusions are not a security boundary. (→ `.claude/rules/rust.md`)
- **Spend is a ledger, not a property of success.** Anything that calls a model logs its usage regardless of outcome.
- **"Not seen this round" ≠ "deleted".** Tombstone only on confirmed absence.
- **Child processes: write, drain and wait concurrently, always under a timeout.**
