## Findings and what changed

| # | Sev | Finding (condensed) | Applied |
|---|---|---|---|
| 1 | High | The export schema accepted `MODEL`/`VERSION`-shaped strings in every field (a heading could pass as a digest). | `t6_private_export.py` rewritten around a field-specific typed schema: every file kind lists its keys, every string has one type (hex64/hex40, opaque id, sample id, ISO timestamp, arm, tool, a verified model allowlist, a version pattern, a closed enum, the `<private>` placeholder); unknown keys and unknown files are refused; nested numeric structures are typed to their Rust structs. |
| 2 | High | Allowed literals learned from public files; the denylist exempted anything `git grep` found in the working tree, including newly introduced leaks. | No learned literals: every enum is fixed in code (resolution strings, trigger text, evidence policies, check names). The denylist's collision filter asks the immutable public baseline (the merge-base with `main`) and applies to headings and excerpts only; the root path, its directory names and every relative path are always listed. |
| 3 | High | `index.json` was copied whole (it carried `embeddings.check.cache_dir`); `indexed_at` was not allowed. | Every export is an explicit scalar projection; the index record projects counts, the embedded count and the model name only; written to a staging directory, validated, then published atomically. |
| 4 | High | The leak scan decoded working-tree JSON, not staged blobs; binary payloads could evade it. | `leak-scan` reads the blobs of the branch's changed files from `HEAD`, staged files from the index, untracked files from the tree; decodes JSON string values from those blobs; refuses binary files in the change except the public corpora's archived graphs; is required once private artifacts exist. |
| 5 | High | `export-private` sorted keys while `questions` wrote insertion order: the committed digest file would change under the freeze. | One canonical serializer, `t6_private_export.py digest-questions`, writes the committed private digests at `questions` and re-derives them at `export-private`, which refuses a difference. |
| 6 | Med | The pre-run commit held private questions but no `schema.json`, so `make check` would fail before `export-private`; card-provenance aggregates were omitted. | No schema file any more (the schema is code); `cards` merges the provenance aggregates into the index record; the smoke test exports a synthetic private run and checks it. |
| 7 | High | `run`/resume rechecked the public freeze only; the private freeze's inputs were never rechecked. | Counted runs of the private corpus re-check the private freeze with a recomputed commitment and require its hash to equal the published digest; the preflight does the same. |
| 8 | High | The preflight compared `src` only, not graphify's serving copy; the freeze recorded graphify's record hash, not the live graph, skill and hooks. | The preflight compares graphify's serving copy against the archive (its own `.claude/`, `CLAUDE.md`, `graphify-out/` aside); the freeze's arm lines hash the served graph, the installed skill, the hook settings and qmd's collection file, so `--check` binds them at every counted run. |
| 9 | High | The store baseline was a mutable `index.json`; reconstruction checked identities and coverage, not card equality or embedding completeness. | The freeze's corpus lines carry each store's sha256 and effective `config.toml` hash; the reconstruction compares section identities, the card text per section hash, and requires every distinct section embedded in both stores. |
| 10 | High | `T2_JOBS`/`T2_MAX_TURNS`/`T2_TIMEOUT`/`T2_RETRIES` and `ARM_WITH_GIT` remained effective in a counted run; the arm set was a positional argument. | A counted run refuses every such override and takes the arm set the preflight certified (recorded in the report); a positional arm set is refused. |
| 11 | High | The freeze required no calibration pilot and recorded aliases, not resolved ids. | `t6.sh calibration "<rule>"` aggregates the pilots into `T6/calibration.json` (agreement per corpus, resolved model ids from the pilot rows, measured throughput, cost, acceptance, the declared resolution rule); the freeze requires and hashes it and prints the resolved ids; the preflight requires the corpus to appear in it. |
| 12 | Med | A recorded binary hash did not establish the binary was built from HEAD. | The preflight runs `cargo build --release --locked` and requires the resulting executable's sha256 to equal the frozen one. |
| 13 | Med | Public verification needed the owner's private freeze file through an environment variable. | The private freeze's sha256 is published as `T6/private/FROZEN.sha256` and the public freeze reads that file; the owner-side preflight additionally checks the live file against it. |
| 14 | Med | `echo "$(sha256 …)"` masked failures into empty fields. | Every value in the T6 freeze blocks is computed by `val`, which dies on failure or emptiness; the public inventories are committed as `T6/<corpus>/pages.txt`. |
| 15 | Med | The commitment hashed the parser's normalised text and swallowed failures. | `sha256(salt ‖ rel_path NUL sha256(file bytes) LF …)` in one Python pass over the inventory; any unreadable file aborts; the plan's text updated (sha256 of file bytes, not blake3). |
| 16 | High | 32 golden pages cannot yield 25 counted plus 10 disjoint pilot questions one per page. | Preregistered allocation: one accepted **counted** question per page (25 or the count reached); the pilot's 10 are the next accepted candidates, distinct sections, any page; `panel.sh questions <n_counted> <n_pilot>` enforces it and labels every accepted row `counted` or `pilot`. |
| 17 | High | The panel saw the writer's facts before listing its own; `facts_required` was unvalidated. | Two calls per member: the first blind (question and section only) returns the member's fact list, validated non-empty strings; the second judges the four criteria and each writer fact against that fixed list. |
| 18 | Med | A 50% list/table threshold exceeded "only a table, list or listing"; denominators and rejections were not committed. | Threshold 90% of non-empty lines; `candidates.summary.json` (headed sections, eligible, documents, excluded by reason, written, refused by reason, judged, accepted counted/pilot) and `questions.rejected.jsonl` are committed for the public corpora and exported as counts for the private one. |
| 19 | Med | Resume trusted candidate ids alone. | Every judged row carries the candidate's content hash and the rubric/model hash; a changed candidate, a changed rubric or a smaller target refuses to resume. |
| 20 | Med | Empty or malformed writer output crashed instead of being a refusal; zero counts aborted under `set -e`. | Empty or malformed structured output is recorded as `writer-no-output`; every count tolerates zero; `questions` dies with a message when nothing was accepted. |
| 21 | High | `jq -r … \| head -1` handed only the first line of multiline references and evidence to both graders. | One JSON record is selected first, then its complete strings are extracted (`t2.sh grade`, `panel.sh regrade`); the smoke test materialises a four-line evidence text and checks it arrives whole. |
| 22 | High | Materialisation verified question and reference hashes only; evidence hashes were trusted; ids and facts unchecked. | `materialise` recomputes the evidence hash from the text, requires unique ids, non-empty `q`/`reference`/`evidence`/`required_facts`, and the committed digest's evidence hash; the smoke test refuses a tampered hash and a duplicate id. |
| 23 | High | Both citation regexes scanned the same text: a backticked odd name yielded a fragment too. | `cite_paths`: backticked spans first, their text removed before the bare-path scan, unique output; the resolver also strips a `t6-<corpus>/` prefix; tested. |
| 24 | High | A malformed trace still left no row; worker failures escaped `wait`. | When `row_of` fails, a schema-valid error row is written for the observation (attempts, wall-clock, cost summed, `error: true`); the completeness gate then counts it as a failure, not a gap. |
| 25 | High | Savings rendering treated `MetricRatio` objects as scalars. | `table` renders each metric's `median_ratio` with its question denominator and the pair's base; `readme-row` names the source-token ratio and its denominator. |
| 26 | Med | The card audit checked array lengths only. | The verdict must list every submitted date and entity once, in order, each with a boolean; otherwise it is incomplete (applies to T6; the T2 archive is untouched). |
| 27 | Med | The block test missed "Generated from …" captions and had no mutation fixtures. | Captions starting with "Generated from" and "Rendered from" are blocks; the baseline page is kept beside the hashes; `selftest` proves a deleted table, a changed caption and a changed heading each fail; in `make check`. |
| 28 | Med | The smoke test stopped before materialisation and citations and never exercised the private export. | The smoke test now covers multiline materialisation with refusals, citation extraction, a private export round trip with three refusals, and the resolver on the copy. |
| 29 | Low | An invalid `${#ARM_TMP[@]:-0}` in an EXIT trap; a dead loop in `archive`. | `ARM_TMP=()` initialised and the trap uses the plain length; the dead loop removed. |

## Second pass (thread `01a179c8-39b1-7fb1-91ab-1c3833df9ade`, pinned `a2c6814`): new or remaining defects, all applied

| # | Sev | Finding (condensed) | Applied |
|---|---|---|---|
| 1 | High | The freeze still failed open: `val` died inside a command substitution, the enclosing `echo` printed an empty field and continued (reproduced on bash 3.2). | `val` also records every failure in a flag file; `vals_ok` refuses to write when any value failed; a final scan of the Inputs refuses any empty field after `sha256`, `fingerprint`, `commitment`, `=` or `:`. |
| 2 | High | `FROZEN.sha256` accepted trailing text; the glob skipped hidden files. | Exactly one 64-hex digest and an optional newline; every file is enumerated with `os.walk` (dotfiles included) and anything not in the allowed list is refused; tested. |
| 3 | High | `calibration` copied the private `pilot.json` whole into a committed file outside the private checker. | Every pilot enters the record through the exporter's typed projection (`project-pilot`); the record is validated against a `CALIBRATION` schema before it is written and in `make check`. |
| 4 | High | The leak scan did not classify untracked files as binary; `jq '.. \| strings'` omitted object keys. | Every scanned blob and working file is classified (`grep -I`); JSON keys are decoded as well as values. |
| 5 | High | Quoted file names from `git diff --name-only` made `cat-file` fail silently. | NUL-delimited names throughout; deletions handled explicitly; a read error is fatal. |
| 6 | High | The exporter deleted the committed directory before comparing digests; the comparison was against the export's own source; the replacement was not atomic; tracked unstaged changes were not scanned. | The staged question digests are compared with the committed ones before anything moves and a difference is refused (the question file is frozen); the replacement renames the old directory aside and removes it only after the new one is in place; the scan covers tracked unstaged changes. |
| 7 | Med | The length threshold dropped mandatory short denylist entries. | The threshold applies to headings and excerpts only; root, directory names and relative paths are always kept. |
| 8 | High | Half-point adjudicated scores became null under an integer schema. | `score`, `sonnet_score`, the panel scores and the member scores are numeric-or-null. |
| 9 | High | The rebuild hashed `$MDA`, not cargo's artifact. | The preflight reads cargo's `compiler-artifact` message for the `mda` executable and requires that artifact, and `$MDA`, to have the frozen hash. |
| 10 | Med | Serving-copy verification covered public markdown only, skipped the private copy and an absent directory, excluded every `CLAUDE.md`. | For every corpus whose graphify build completed, the serving copy's whole tree is compared with the source copy (only the store, the root `.claude/`, the root `CLAUDE.md` and `graphify-out/` excepted); an absent directory fails. |
| 11 | Med | Process-substitution SQL failures compared as equal empty output. | Every query runs into a checked variable (`sq`), non-empty results are required, a failed query is fatal. |
| 12 | Med | Low-count corpora never reached the pilot; an empty pilot aborted. | Preregistered allocation: a candidate is counted while the counted target is open and its page is free; otherwise pilot while the pilot target is open; otherwise skipped. An empty pilot is tolerated and recorded (the calibration rests on the other corpora). |
| 13 | High | Resume reached the target before validating; hashes excluded page, heading and section id; only the combined target was bound. | Every judged row is validated against the candidates file before the loop; the identity hash includes page, heading and section id; the targets are recorded in `questions.targets.json` and a different pair refuses. |
| 14 | Med | `required_facts: [{}, {}]` crashed the writer; the panel's verdicts were not type-checked. | The writer's output is validated field by field (non-empty `q`, every fact an object with non-empty `fact` and `span`); the panel requires real booleans, a boolean per writer fact and a non-empty list of non-empty strings. |
| 15 | Med | Full-text samples bypassed materialisation checks; fact elements unchecked. | One validator (`validate_full`) for every T6 question file with texts: unique ids, non-empty texts, evidence hash recomputed, facts non-empty strings, `relevant` present; the committed `required_facts_n` is checked too. |
| 16 | High | `docs/a.mdx` became `docs/a.md`; backticked anchors disappeared; `t6-<corpus>/` was not stripped. | Whole extensions with a boundary, an optional `#anchor` dropped, both qmd prefixes stripped; tested in the smoke test. |
| 17 | Med | The calibration's "grader" was the requested alias; the preflight checked presence only. | Resolved ids come from `grade.model`, `grounding.model`, the rows' `models` and the members' `model`; the preflight requires a conforming record with pilot runs, resolved ids and a rule. |
| 18 | Med | A bare `wait` hid worker failures; success did not require completeness. | The runner waits on each worker's pid, counts non-zero exits, and exits 3 unless every expected observation has a row. |
| 19 | High | A tracked `__pycache__/*.pyc` blocked the leak gate (binary in the change). | The bytecode is untracked and ignored (`__pycache__/`, `*.pyc` in `.gitignore`). |
