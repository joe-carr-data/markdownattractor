## 3. Patterns → rules

- **A record's verdict comes from the process, not the artifact**: exit status, terminal result and completion evidence decide "completed"; a file on disk does not.
- **`//` is not a boolean default in jq**: `false // x` is `x`; test booleans with `==`.
- **The artifact an arm scores from is frozen by its own hash**, and the served copy must equal the archived one before a drive runs.
