# aha archive — 2026-09

Entries pruned from `docs/aha.md` (kept under 60 lines), oldest last.

- 2026-09-22 — A time-based nonce in the section delimiter broke the "stdin equals user_message(req)" test; a per-process keyed hash gives the same unpredictability and stays deterministic within a process.
- 2026-09-22 — Injection check: a section containing a literal `</section>` plus "reply HACKED" still produced a correct card 3/3 with the nonce-tagged delimiter.
- 2026-09-22 — Local backend, first live runs on an M3 24 GB that was already swapping (Docker VM + Chrome, 26 GB swap in use): gpt-oss-20b with `--ctx-size 0 -np 4` threw Metal "command buffer failed" and every request came back HTTP 500 "Compute error"; the engine classified them retryable, retried, and recorded the failures cleanly. Gemma 3 4B Q4 with full context and 4 slots loaded without errors and produced good cards, but at 53 tok/s prefill and 6 tok/s decode (≈ 2 min per section) because the model was paged. Memory residency, not model size, is the local backend's first-order variable. The guide now says so.
- 2026-09-22 — Local pool defaults: start 2, cap 4, 300 s per call, whatever `concurrency` says. A single model on one GPU gains nothing from a deeper queue; it only converts waiting into timeouts.
- 2026-09-22 — First live run of the `api` backend hit three things in a row, none of them code: the key needed an `anthropic-workspace-id` header (keys not scoped to a workspace), the org had no credits, and then the real bug: schemars encodes unit enums as `oneOf` of `const`s, which the structured-outputs API rejects. `simplify_enums` rewrites those to plain `enum`. After that: 10/10 cards, one API turn each, 15 s wall for 10 sections at 4–5 concurrent, $0.043. Same sections took 32 s and two turns each through `claude -p`.
- 2026-09-22 — Structured outputs via `output_config.format` fix the "reminder turn" problem for free: `turns` is exactly 1 per call on the API, so input tokens per section are ≈ 2.4K instead of ≈ 5K.
- 2026-09-22 — Codex review of the engine: 14 findings, all accepted. The three High ones were real: path escape via symlink, a stdin/stdout pipe deadlock on chatty children (reproduced: hangs 20 s on the old code), and concurrent runs overwriting a summarized row with `failed`. A second model reading cold code found what the author normalised. Keep the cadence.
