## 6. Caveats and traps (each cost time this session; most are in `docs/aha.md`)

- **Bash reads a running script incrementally**: never edit a script that is executing (t1.sh broke mid-chain). Write via atomic replace (`os.replace` from Python) and only between runs.
- **Any `scripts/eval/*` commit under a frozen table breaks `freeze.sh --check`**; re-writing the freeze postdates rows. Batch renderer fixes to the next milestone (the T3 MiB/reconstruction fix was deferred to M7 for this reason).
- **`set -euo pipefail` + `grep` no-match kills `$(…)`** assignments; `head` under pipefail throws SIGPIPE into jq → use jq `.[:n]`; use Python for non-trivial text steps.
- **jq**: `as` is a reserved word (`$as` fails), comparisons inside object constructors need parentheses, apostrophes inside single-quoted programs break the shell, `index([.])` binds the array (use `. as $pg`), empty `select … as` binding → `first(...) // null`.
- **qmd**: search JSON `file` is `qmd://<collection>/<path>?index=…`; `llm_cache` shortens re-asked warm queries (cold every run, rule 0.9); concurrent fingerprint reads corrupt without a busy timeout (`qmd_fingerprint` is fail-closed with a mkdir lock in `t1.sh`).
- **graphify**: returns `.tsx` and sourceless nodes; the driver drops empty `src=` paths and the pooled sampler restricts to corpus pages; its Sonnet build fails on the large corpora (Prisma, GitHub Docs), so the Haiku build is the arm there and is labelled `graphify-haiku`; its graph tool went unused in every T4 answer.
- **Agents read the file when the question names the page**: T4's first attempt proved nothing; endpoint questions and probes must make the agent find the page.
- **`git add crates && git commit` commits the whole stale index**; stage explicit paths.
- **Flaky worker timeout test**: margins raised to 6 s / 20 s (`crates/mda-core/src/worker/tests.rs`); if it flakes again, that is the knob.
- **Counts share a unit before comparison**: `sections` are rows, `summarized`/`pending` are distinct hashes.
- **Codex record hygiene**: pinned commit, thread id, verdict wording quoted, deferred findings named with the milestone that picks them up.
- **The scratchpad is per session** (`/private/tmp/claude-501/…/scratchpad/m4/page-*.md` holds the page templates); anything needed later must live in the repo.
- Old SHAs in pre-2026-09-22 docs are stale (history rewrite).
- The GitHub Actions billing blocker in STATUS is historical (PR #10) and CI ran green for #22–#34; leave the STATUS line until the owner clears it.
